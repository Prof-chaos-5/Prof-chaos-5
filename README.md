## 👋 About Me

🎓 **B.Tech in CSE** at GB Pant Engineering College, New Delhi (2027)  
🔍 I build **RAG systems, multi-agent workflows, and computer vision models**, and ship them as working products.

- 💼 **AI Engineering Intern**, *Mythyaverse*: LangGraph + Gemini pipelines for automated math Q/A generation (**~40% lower inference cost** via Batch API); FastAPI + Twilio/Slack integrations for a crypto wallet client.
- 🔬 **AI Research Intern**, *IIT Roorkee*: applied NLP and RAG on confidential public-sector projects (corpus curation, ingestion pipelines, retrieval evaluation).
- 🛰️ **Virtual Training**, *ISRO-IIRS*: AI/ML for geospatial problems (CNN, RNN, RCNN, SSD, YOLO) with Google Earth Engine.
- 🏆 **Top 10**, Google Cloud GenAI Exchange Hackathon (Nexora).
